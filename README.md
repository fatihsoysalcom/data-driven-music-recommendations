# Data Driven Music Recommendations

This example demonstrates a core concept of data-driven applications: collecting user interaction data, analyzing it to infer preferences, and then using these insights to provide a personalized experience. It simulates a music streaming service that recommends songs based on a user's listening history and preferred genres, highlighting how value can be created through personalization rather than direct e-commerce.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
